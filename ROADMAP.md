# Roadmap

VerifySignal is pre-1.0. This is directional, not a commitment. See
[GOVERNANCE.md](GOVERNANCE.md) for how decisions are made, and the
[open issues](https://github.com/RigelRise/verifysignal-spec/issues) for what is
in flight.

## Now

- Ship to PyPI via Trusted Publishing, so `uv tool install verifysignal-spec` is the one-line install.
- Cut the first tagged release with notes.
- Grow the [`examples/`](examples/) gallery and record the demo.

## Next

- More coding-agent integrations beyond Claude Code and Codex.
- Richer, safer repair autonomy.
- Record and replay run fixtures for fast, offline reruns.

## Later

- Target surfaces beyond the browser.
- A hosted docs site.
- Discussions, a chat channel, and a curated "good first issue" set.

Have a request? Open a
[feature request](https://github.com/RigelRise/verifysignal-spec/issues/new/choose)
or start a
[discussion](https://github.com/RigelRise/verifysignal-spec/discussions).
