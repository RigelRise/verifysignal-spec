# Roadmap

VerifySignal is pre-1.0. This roadmap is directional, not a commitment — see
[GOVERNANCE.md](GOVERNANCE.md) for how decisions are made, and the
[open issues](https://github.com/RigelRise/verifysignal-spec/issues) for what is
actually in flight.

## Now

- Ship to PyPI via Trusted Publishing, so `uv tool install verifysignal-spec` is
  the one-line install.
- Cut the first tagged release with published notes.
- Grow the [`examples/`](examples/) gallery with more real flows and record the
  README demo GIF.

## Next

- Broader coding-agent integrations beyond Claude Code and Codex.
- Richer, safer repair autonomy.
- Record / replay run fixtures for faster, offline reruns.

## Later / exploring

- Target surfaces beyond the browser.
- A hosted documentation site.
- Community surface: GitHub Discussions, a chat channel, and a curated
  "good first issue" set.
